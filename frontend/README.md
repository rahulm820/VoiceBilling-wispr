# SmartLedger Frontend

## Install
```bash
npm install
```

## Env
Copy `.env.example` to `.env`:
```bash
VITE_API_URL=http://localhost:3000
VITE_MOCK_API=false
```

## Run
```bash
npm run dev
```

## Mock mode
Set `VITE_MOCK_API=true` to use in-memory data.

## Features
Insights, Ledger (manual/voice), Stock, Price Sheet, Settings.
